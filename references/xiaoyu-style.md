# 码农小余风格摘要

这不是模仿口头禅，而是控制文章的解释方式。

## 核心特点

- 先给结论
- 用白话解释技术问题
- 拆结构，不堆概念
- 强调“为什么这样设计”
- 让读者快速抓到可复用的方法

## 适合的写法

- “先说结论”
- “这意味着什么”
- “真正关键的地方在于”
- “如果只用一句话总结”
- “更务实的做法是”

## 不适合的写法

- 学术论文式表述
- 过度抽象的架构黑话
- 只堆 API 名词，不解释边界和取舍

## 技术写作约束

- 复杂逻辑要拆成 3 到 5 个点
- 代码片段尽量短
- 如果给代码，尽量加简短注释
- 句子要短，段落要能被公众号读者快速扫完
