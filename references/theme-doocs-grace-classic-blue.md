# Doocs 优雅主题经典蓝规范

这份规范用于固定公众号文章的 Doocs 风格主题，避免每次渲染都出现不同的强调色。

## 目标

- 结构风格：沿用 Doocs `grace`
- 主题主色：经典蓝 `#0F4C81`
- 适用范围：本地渲染 HTML、发布前兼容内联化、后续 skill 默认值

## 设计原则

- 保留 `grace` 的圆角、阴影、分隔线和层次
- 不使用紫色、粉紫、灰紫作为强调色
- 主题相关的强调元素统一使用经典蓝，不做多色漂移

## 主题令牌

- `primary`: `#0F4C81`
- `accent`: `#0F4C81`
- `dangerous legacy accent`: `#92617E`

## 元素约束

- `h2`: 胶囊标题底色使用 `#0F4C81`
- `h3`: 左侧边线和底部虚线使用 `#0F4C81`
- `strong`: 强调文字使用 `#0F4C81`
- `blockquote`: 左侧边线优先使用 `#0F4C81`
- 其他所有由 `var(--md-primary-color)` 驱动的元素都应落到 `#0F4C81`

## 执行要求

- 首选直接给渲染器传入正确主色
- 如果渲染链路做不到，就在最终 HTML 上统一替换错误主题色
- 发布前检查 HTML 中是否还残留 `#92617E`

## 验收标准

- HTML 中不再出现 `#92617E`
- 标题、强调、边线视觉上统一为经典蓝
- 页面整体仍然保持 Doocs `grace` 的优雅结构，而不是退回默认主题
