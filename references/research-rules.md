# 素材补强研究规则

这份规则用于“整理素材”阶段，指导什么时候要联网补充信息，以及补什么信息才算高质量。

## 什么时候应该补充搜索

遇到下面任意一种情况，就应该做网络补充研究：

- 原始素材过短，只够做摘要，不够支撑成文
- 需要背景信息，原素材没有讲清
- 需要与其他产品、框架、方案做对比
- 需要例子、引用、真实落地场景
- 文章涉及会变化的事实
- 用户明确希望“深度理解”“补充更多信息”“不要只改写原文”

## 补什么

优先补这几类内容：

- 官方文档
- 仓库主页与 README
- release notes / changelog
- 作者或维护者的长文 / 演讲 / 访谈
- 高质量第三方技术分析
- 真实案例与实践经验

## 不要补什么

下面这些信息通常噪音更大：

- 低质量洗稿
- 没有一手出处的二次转述
- SEO 农场文章
- 只给结论、不给依据的测评

## 研究输出应该是什么

不是一堆链接，而是一份可写作的素材补充清单，比如：

- 背景事实
- 关键定义
- 官方定位
- 与竞品的差异
- 真实案例
- 重要引用

## 写回文章时的原则

- 补强主线，不要打断主线
- 补进去的是“解释力”，不是“资料堆”
- 一篇公众号文章通常只需要最有用的 3 到 7 条补充信息
